# Make a commentary reel from a new video

Use the experimental `coach.tiktok_reel` CLI for Chinese, player-named commentary. It is separate from the app and the teaching exporters. Use singles footage that shows the court from behind a baseline. Supply short player names for near and far at the first reliable rally. Verify those names from the frames, not the order in a video description.

## Install the inputs once

Use Windows, Python 3.12, ffmpeg, and a Chinese font. Install the full app requirements, not only `requirements-reels.txt`.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts\get_models.py yolo kokoro tracknet
.\.venv\Scripts\python.exe fast\prepare_cache.py
```

The model downloader fetches the pinned TrackNet runtime and checkpoint. The CLI compiles its own OpenVINO shuttle model on first use. Kokoro v1.1 uses speaker 60. No lab folder or old rendered MP4 is required.

## Generate a reel

Supply a video that you have permission to process and an attribution JSON file. External sources need `author`, `license`, `source_url`, and `license_url`. URLs must use HTTPS. The CLI also accepts the nested attribution in [`sample-videos/source-attribution.json`](../sample-videos/source-attribution.json), but that credit applies only to its Arise recording.

Your own recording or a privately permitted recording does not need invented public URLs. Use `source_kind: "self_recorded"` or `"private_permission"` and state the creator, rights, and your permission explicitly. For example, save this as `credit.json`, replacing the statements with your actual circumstances:

```json
{
  "source_kind": "self_recorded",
  "author": "Local recorder",
  "license": "Private use; not licensed for redistribution",
  "rights_statement": "I recorded this match and have permission to process the footage."
}
```

Optional URLs still must use valid HTTPS. The tool does not verify permission, infer rights, or apply the sample recordings' credit to your video. Permission to process a file is not necessarily permission to publish the reel.

```powershell
.\.venv\Scripts\python.exe -X utf8 -B -m coach.tiktok_reel MATCH_VIDEO outputs\my-commentary `
  --near "近端选手名" --far "远端选手名" --attribution-json credit.json
```

Use a new output directory. An existing directory is rejected without changing its files. Use `--lock PATH` to share a CPU lease with another run. Use `--font PATH` for a different Chinese TrueType or OpenType font.

The command normalizes actual video timestamps to 30 fps, rather than trusting a duration header. It runs fresh court, player, pose, and shuttle inference. It selects candidate rally excerpts and writes short lines from supported shot or placement evidence. It does not learn a style or prove that its choices are exciting.

The output includes:

| File | Use |
|---|---|
| `tiktok.mp4` | Portrait 1080 by 1920 video at 30 fps, normally 26.6 seconds |
| `plan.json` | Selected source windows, identities, action cues, speech, captions, green tags, and evidence |
| `verification.json` | Full output decode, picture and text checks, encoded voice coverage, and this run's MP4 hash |
| `contact-sheet.jpg` | Selected narration cues |
| `analysis.json`, `pose.json`, `normalized.mp4` | Fresh model estimates and the normalized source |
| `plan.draft.json` | A source-bound starting point for a reviewed plan, even when automatic selection fails |
| `frame-map.json`, `render-inputs.json`, `voice-check.json`, `run.json` | Source-frame mapping, input hashes, pronunciation warnings, review provenance, and wall time |

Review the video before publishing. The media checks do not approve shot names, pronunciation, or voice naturalness. Footage rights remain separate from the code.

## Edit the plan without repeating inference

Keep the original `normalized.mp4` and `pose.json` files. The plan binds their relative paths and hashes. Edit a copy of `plan.json`, then use a new destination:

```powershell
.\.venv\Scripts\python.exe -X utf8 -B -m coach.tiktok_reel MATCH_VIDEO outputs\reworded `
  --plan outputs\my-commentary\plan.json
```

This mode checks the original source hash and bound assets, skips inference, synthesizes fresh speech, and renders again. Fresh voice length and MP4 bytes can differ. A recorded SHA256 identifies one run, not expected regenerated bytes.

Keep `caption_chunks` joined exactly equal to `caption`. Keep measured metres and seconds in estimate-labelled green tags. Ordinary phrases such as `这一拍`, `两人头顶对角互拉`, and `四方球` are allowed. A reviewer's wording remains a reviewer's claim, not an automatic classification result.

## Start with a reviewed plan

If automatic selection lacks enough evidence, inspect the saved `plan.draft.json`. You can also request that draft without rendering:

```powershell
.\.venv\Scripts\python.exe -X utf8 -B -m coach.tiktok_reel MATCH_VIDEO outputs\analysis-only `
  --near "近端选手名" --far "远端选手名" --attribution-json credit.json --analyze-only
```

Copy `moment_template` into `moments`. Fill its source bounds and cue frames using the normalized video's 30 fps timeline. Fill the actual player, speech, caption chunks, tag, and visual evidence note. Leave `shot_family` null when uncertain.

Set `review_status` to `reviewed_plan`. Add `reviewer`, `reviewer_kind`, and `review_note`. Use `reviewer_kind: "agent"` for an agent's frame review. Use `"human"` only when a person actually attests to the review. Set each line's `claim_source` to `reviewed_plan` and fill `evidence.review_note`. Run `--plan` on that completed file.

A draft cannot render until those fields are complete. A failed automatic selection is not evidence that a reviewed claim is correct. If the court or both players cannot be established, the command fails instead of producing a reel.

## Review identities and shot claims

Near and far names refer to the first reliable rally. The CLI compares measured torso colours to that rally when players change ends. Similar kits, a new camera angle, or an occluded torso can make identity uncertain. To supply reviewed side assignments, pass `--sides FILE` with a list such as:

```json
[
  {"start_s": 0, "end_s": 120, "near": "近端选手名", "far": "远端选手名"}
]
```

Use the actual reviewed intervals and the same two names supplied to the CLI. Do not copy one side assignment across an uncertain change of ends.

Automatic family names are limited to strongly supported clear and lift trajectories. Other lines describe supported placement or a deep-then-short sequence. They do not invent smash, drop, jump, or backhand claims. Contact confidence is a heuristic score, not a calibrated probability.

For comparison with the incomplete AI-made China Open annotations, use:

```powershell
.\.venv\Scripts\python.exe scripts\evaluate_reel_analysis.py outputs\my-commentary\analysis.json `
  --labels studio\tactics\inputs\labels.json --out outputs\scoped-agreement.json
```

This reports agreement only on confidently annotated, matched hits, plus abstentions and candidate coverage. Unmatched predictions are not false positives. Do not call this whole-match accuracy or human-certified precision.

The [workflow status](tiktok-style-workflow.md) separates this experimental CLI from the approved fixed-match rebuild and the teaching exporters. The Arise test recordings are 120-second and 110-second browser-captured excerpts, not complete matches. Uneven capture timing, repeated frames, and missed shuttle pictures limit their evidence. They are not bit-for-bit downloads of the original upload.
